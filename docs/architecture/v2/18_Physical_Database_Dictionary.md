## Standard Column Conventions

| Pattern | Type / rule |
|---|---|
| `*_id` primary/foreign keys | `uuid` |
| `*_at` | `timestamptz` |
| `*_version` | `text` + version-registry reference where conclusion-affecting |
| `*_hash` | canonical text digest or `bytea` |
| `confidence` | bounded numeric 0–1 |
| flexible source/event payload | `jsonb` |
| large content | object-storage locator + content hash |
| security classification | FK to `security.security_classifications` or equivalent compact key |
| tenant/security scope | `scope_id uuid` on scope-bearing rows; inherited per Document 21 |
